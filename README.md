# 📊 Social Media Sentiment Analysis Dashboard

## 🚀 Overview

This project is a Machine Learning + NLP based dashboard that analyzes social media text and classifies sentiment into:

* 😊 Positive
* 😐 Neutral
* 😡 Negative

It uses **TF-IDF + Logistic Regression** and visualizes results using **Streamlit**.

---

## 🎯 Problem Statement

Businesses receive thousands of comments daily. Manual analysis is slow and inefficient.

This system automates sentiment detection and provides instant insights.
